(async, static) addAsset(statsId, aData) → {Promise.<Asset>}

Adds an asset to the game statistics for the given statsId. Determines the asset type (Nature or Asset), creates an instance, and adds it via the repository. After adding, checks if any asset-related achievements have been achieved and adds them to the game statistics if so.
Parameters:
Name Type Description
statsId string The id of the game statistics object to associate the asset with.
aData Object The data for the asset to be added.

yLocation number The y-coordinate location of the asset.
xSize number The width of the asset.
ySize number The height of the asset.
