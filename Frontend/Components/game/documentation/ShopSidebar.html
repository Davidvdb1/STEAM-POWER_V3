Class: ShopSidebar

ShopSidebar()

ShopSidebar component for displaying a sidebar with various cards representing assets. Each card can be dragged and dropped, and the prices are updated based on the current coins available. The component listens for currency updates to adjust the prices accordingly.

Constructor

new ShopSidebar()

Creates an instance of ShopSidebar. Initializes the shadow DOM and sets up event listeners for card drag events and currency updates.
