(static) createCheckpointLoadPopup(scene)

Creates a checkpoint load popup in the given Phaser scene. This popup allows players to select a checkpoint to load from a list fetched from the server. It includes a close button, title, dropdown for checkpoint selection, and handles user interactions to load the selected checkpoint.
Parameters:
Name Type Description
scene Phaser.Scene The Phaser scene where the popup will be created.
